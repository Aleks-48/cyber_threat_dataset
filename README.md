## 🇷🇺 Описание проекта (Русский)
Данный репозиторий содержит воспроизводимый программный комплекс для сбора, первичной валидации, PII-анонимизации, аудита качества текстовых данных и обучения baseline-моделей машинного обучения по киберугрозам: **Тема 8 — «Опасное воздействие и вербовка» (`HARMFUL_INFLUENCE`)**.
### 📌 Исследуемые подвиды угроз:
1. `EXTREMIST_PROPAGANDA` — Экстремистская и радикальная пропаганда
2. `EXTREMIST_RECRUITMENT` — Прямая или косвенная вербовка в деструктивные ячейки
3. `VIOLENCE_GLORIFICATION` — Романтизация и оправдание массового насилия (скулшутинг, теракты)
4. `DANGEROUS_CHALLENGE` — Опасные челленджи (руфинг, зацепинг, удушье)
5. `SELF_HARM_ENCOURAGEMENT` — Склонение к селфхарму, нанесению порезов и шрамов
6. `SUICIDE_ENCOURAGEMENT` — Склонение к суициду («синий кит», «тихий дом»)
7. `CRIMINAL_RECRUITMENT` — Вовлечение в преступную деятельность (закладки наркотиков, дропперство)
8. `GROUP_LOYALTY_PRESSURE` — Психологический прессинг на безусловную верность группе
9. `SECRET_COMMUNICATION_REQUEST` — Призывы уйти в секретные чаты (Threema, Session)
### 🤖 Сравнение baseline-моделей (5 ML/NN архитектyp):
В репозитории реализован модуль обучения и оценки 5 алгоритмов классификации:
- **Neural Network (MLP)** — `F1: 100%` (Лидер, глубокий анализ признаков)
- **Random Forest** — `F1: 94.4%` (Высокая стабильность и точность)
- **Support Vector Machine (SVM)** — `F1: 82.3%` (Уверенная классификация)
- **Logistic Regression** — `F1: 60.4%` (Базовый уровень, частые пропуски)
- **Naive Bayes** — `F1: 45.0%` (Слабая устойчивость к контекстному шуму)

## 🇰🇿 Жоба туралы (Қазақша)
Бұл репозиторий киберқауіптер бойынша мәтіндік деректерді жинау, бастапқы тексеру, PII анонимдеу, сапа аудиттеу және baseline машиналық оқыту модельдерін сынауға арналған автоматтандырылған кешенді қамтиды: **8-тақырып — «Қауіпті әсер және тарту/азғыру» (`HARMFUL_INFLUENCE`)**.
### 📌 Зерттелетін қауіп қосалқы түрлері:
1. `EXTREMIST_PROPAGANDA` — Экстремистік үгіт-насихат пен деструктивті манифестер
2. `EXTREMIST_RECRUITMENT` — Деструктивті ұйымдар мен топтарға тарту
3. `VIOLENCE_GLORIFICATION` — Жастар арасындағы зорлық-зомбылықты дәріптеу (скулшутинг)
4. `DANGEROUS_CHALLENGE` — Өмірге қауіп төндіретін ойындар мен челлендждер (зацепинг, руфинг)
5. `SELF_HARM_ENCOURAGEMENT` — Өзіне дене жарақатын салуға үгіттеу (селфхарм)
6. `SUICIDE_ENCOURAGEMENT` — Суицидке азғыру («көк кит», деструктивті ойындар)
7. `CRIMINAL_RECRUITMENT` — Қылмыстық әрекеттерге тарту (курьер-закладкалар, дропперлік)
8. `GROUP_LOYALTY_PRESSURE` — Топқа адалдықты талап ететін психологиялық қысым
9. `SECRET_COMMUNICATION_REQUEST` — Құпия чаттарға шақыру (Threema, Session)

## 🚀 Быстрый старт / Жылдам іске қосу
### 1. Установка зависимостей / Тәуелділіктерді орнату:
```bash
git clone https://github.com/Aleks-48/cyber_threat_dataset.git
cd cyber_threat_dataset
pip install -r requirements.txt
```
### 2. Запуск тестов / Тесттерді орындау:
```bash
pytest tests/
```
### 3. Запуск веб-дашборда / Веб-интерфейсті қосу:
```bash
streamlit run web_app.py
```
*(Қолданба жергілікті түрде `http://localhost:8501` мекенжайында ашылады)*
