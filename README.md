# Cyber Threat Dataset Pipeline — Theme 8

Исследовательский прототип для аудита текстовых данных о девяти подвидах
`HARMFUL_INFLUENCE` и сравнения пяти бинарных baseline-моделей. Интерфейс
показывает данные, результаты проверок и метрики.

Файл `06_candidates/candidates_with_sources.csv` содержит все 13 500
записей и присоединённые поля источника: название канала, платформу, URL и
описание. Значение `DECLARED_OSINT` означает, что источник внесён в реестр
проекта как открытый; это не является независимым подтверждением доступности
URL или происхождения каждого текста.

> **Статус набора данных: демонстрационный.** В текущих 13 500 строках только
> 297 уникальных текстов. Сырой снимок содержит заглушку `Raw dialogue` и не
> подтверждает тексты кандидатов. Одинаковые тексты имеют разные языковые
> метки. Аудит блокирует переход к следующему этапу. Показатели модели на этом
> наборе нельзя использовать как оценку работы на реальных переписках.

## Категории

1. `EXTREMIST_PROPAGANDA`
2. `EXTREMIST_RECRUITMENT`
3. `VIOLENCE_GLORIFICATION`
4. `DANGEROUS_CHALLENGE`
5. `SELF_HARM_ENCOURAGEMENT`
6. `SUICIDE_ENCOURAGEMENT`
7. `CRIMINAL_RECRUITMENT`
8. `GROUP_LOYALTY_PRESSURE`
9. `SECRET_COMMUNICATION_REQUEST`

Аннотации имеют четыре класса: `TARGET_THREAT`, `OTHER_THREAT`, `NORMAL`
и `UNCERTAIN`. Модели сейчас решают **только бинарную задачу**:
`TARGET_THREAT` против `OTHER_THREAT` и `NORMAL`; неопределённые
записи исключаются из обучения. Девять подвидов у кандидатов не являются
предсказанием обученной модели.

## Запуск

Требуется Python 3.11+.

```bash
pip install -r requirements.txt
python run.py
python train_models.py
pytest tests/
streamlit run web_app.py
```

`run.py` пересчитывает `09_verdict/stage_verdict.json`. В `config.yaml`
заданы квоты и пороги. `run_all.py` останавливается с кодом 1, когда аудит
заблокирован. `train_models.py` можно запустить отдельно для исследовательской
оценки демонстрационных текстов; она сохраняется вместе с
`10_model_baselines/evaluation_metadata.json` и пометкой `DEMO_ONLY`.

При оценке одинаковые тексты сначала объединяются, затем разделяются на
обучающую и тестовую части. TF-IDF обучается только на обучающей части.
Предсказания не изменяются после обучения. Это устраняет точное совпадение
текстов между частями, но шаблонная структура текущих фраз всё равно
ограничивает значение метрик.

Пять моделей выводятся от лучшей к худшей. Сначала сравниваются F1, Accuracy
и Recall, затем скорость предсказания и обучения. Для каждой модели
сохраняются назначение, сильная сторона и ограничение. Если качество
одинаково, место определяется скоростью именно этого запуска.

Для нового локального экспорта доступна проверка записей и первичная очистка:

```bash
python 03_collection/collect.py --input supplied.jsonl --output validated.jsonl
python 05_cleaning/clean.py --input validated.jsonl --output cleaned.csv
```

Каждая входная запись должна содержать `dialogue_id`, `source_id`,
`target_subtype`, `language` и `text`. Сборщик проверяет утверждённый
идентификатор источника и не принимает пустой текст или заглушку. Очистка
удаляет точные повторы и маскирует некоторые контактные данные. Её
эвристики не заменяют ручную проверку персональных данных.

## Что проверяет аудит

- число кандидатов и уникальных текстов в каждом подвиде;
- целостность идентификаторов, выборки из 100 примеров на подвид и разметки;
- доли `TARGET_THREAT` и `UNCERTAIN`;
- привязку кандидатов к утверждённым источникам;
- хеши снимка, словаря и списка источников;
- совпадение текста кандидата с исходной записью;
- противоречивые языковые метки одинаковых текстов.

Порог по доле `UNCERTAIN` служит сигналом качества набора данных. Он не
является инструкцией менять экспертную метку ради достижения показателя.

## Ограничения и следующий этап

Список источников в репозитории не подтверждает, что адреса существуют, что
был получен доступ к перепискам или что допустима их публикация. Для
реального исследования потребуются проверенные источники, история сбора,
исходные тексты с безопасной анонимизацией, независимая разметка и новые
примеры без шаблонных повторов. До этого блокировка аудита ожидаема.
Файлы оценки качества ключевых слов и источников содержат только заголовки:
прежние значения `0.85` не подтверждались расчётом.
Внешний сбор данных и развёртывание приложения в этом репозитории не выполняются.
