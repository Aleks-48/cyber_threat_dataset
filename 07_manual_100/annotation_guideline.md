# Руководство по экспертной разметке диалогов (Тема 8: HARMFUL_INFLUENCE)

## Описание задачи
Ваша цель — классифицировать каждый диалог (из выборки 100 диалогов на подвид) на одну из четырех категорий.

## Категории разметки

1. **TARGET_THREAT (Целевая угроза)**
   - Подтвержденное наличие заявленного подвида опасного воздействия или вербовки (например, прямая вербовка в деструктивную группу, склонение к суициду/селфхарму, пропаганда скулшутинга).

2. **OTHER_THREAT (Иная угроза)**
   - Деструктивный контент присутствует, но он относится к другой категории (например, буллинг, доксинг, мошенничество), а не к заявленным 9 целевым подвидам.

3. **NORMAL (Безопасный контент / Ложноположительное срабатывание)**
   - Бытовое общение, шутки, сарказм, ролевые игры, новостные репортажи, цитирование без злого умысла.
   - Активное осуждение вербовки (Counter-speech).

4. **UNCERTAIN (Неоднозначный контент)**
   - Контекст слишком двусмысленен или фрагментарен для однозначного вердикта. Требуется расширение контекста (дополнительные реплики).

## Дополнительные указания
- Обращайте внимание на завуалированный сленг, транслит и намеренные искажения.
- Если контекста недостаточно для решения, выбирайте UNCERTAIN и запрашивайте дополнительные реплики. Для NORMAL нужны признаки безопасного контекста, а не просто отсутствие явной угрозы.
- Порог 15% для UNCERTAIN используется в аудите качества выборки. Он не должен влиять на экспертное решение по отдельному диалогу.
