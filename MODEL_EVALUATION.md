# Анализ пяти моделей

`python train_models.py` обучает пять открытых алгоритмов scikit-learn: Logistic Regression, Multinomial Naive Bayes, Linear SVM, Random Forest и MLP. Их реализация и описание доступны по ссылкам в `10_model_baselines/model_metrics.csv`. Это локально обучаемые классификаторы, а не внешние ИИ-сервисы и не предобученные языковые модели. Данные не отправляются третьим сторонам.

Задача: отличить `TARGET_THREAT` от `OTHER_THREAT` и `NORMAL`. Разметка `UNCERTAIN` исключена. Для оценки сначала удаляются точные повторы размеченных текстов, затем выполняется стратифицированное разделение 80/20 с seed 42. На текущем снимке это 166 уникальных размеченных текстов: 132 для обучения и 34 для проверки. Каждый алгоритм получает отдельный TF-IDF конвейер, обученный только на обучающей части. Результаты и параметры оценки сохраняются в `10_model_baselines/model_metrics.csv` и `10_model_baselines/evaluation_metadata.json`.

Оценка 0–5 вычисляется как F1 в процентах, делённый на 20. Место определяется только F1; при равенстве модели делят место. На текущей тестовой части все пять алгоритмов получили 100% и делят первое место. Это **не** означает подтверждённое качество 5/5 на реальных новых данных: аудит датасета не пройден, тексты шаблонно похожи, а тестовая часть очень мала. Достоверно назвать модель лучше или хуже по этим данным нельзя. Прежняя таблица с разными неподтверждёнными оценками заменена результатом воспроизводимого запуска.

После обучения каждый конвейер формирует бинарный прогноз для всех 13 500 записей. `10_model_baselines/model_predictions.csv` содержит ID записи, ID источника и пять прогнозов; `1` означает автоматический прогноз `TARGET_THREAT`, а не проверенную ручную метку. В Streamlit можно увидеть сравнение моделей, сводку по каналам и скачать полный датасет с пятью прогнозами. Для внешней проверки качества нужны новые независимые тексты с подтверждённым происхождением и разметкой, а также исправленный аудит качества.
